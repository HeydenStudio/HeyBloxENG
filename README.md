# HeyBlox
HeyBlox Project Description
HeyBlox is a revival based on Novetus where you can publish your accessories, publish your places, etc. (The source code will be on GitHub soon, once the first version of HeyBlox is out.)

How your accessories will be published
At first, the forum admins will gather the worthy accessories, etc. (30 accessories or fewer), and then I'll add them to the HeyBlox files by publishing an update on GitHub, which you'll need to download so your accessories show up in the game.

How to publish your game
You drop the rbxl file of your game into #публикация-плейсов-🗯 and soon your place will be added to the site.

How to download / How to connect
How to download
The latest version of HeyBlox is already on GitHub (https://github.com/HeydenStudio/HeyBlox/releases/tag/05). 1. Download the zip file. 2. Open the C drive. Then create a folder called HeyBlox in it and extract the zip archive into that folder. And play!

What is it / What's the difference / How
How to connect to the official servers
Download Radmin VPN and run it, then click "Network", then "Join network", then "Private network", and enter the name: "HeyBlox" and the password "HeyBloxOnline". Then download the LATEST version of HeyBlox and run it. Click the Versions button and select version 2011M if you want to play games from 2011 to 2017, or another version listed in #сервера-🌐. Then find the JoinServer tab in the "play" tab, type "26.222.162.192" in the Server IP Address field, then go to the #сервера-🌐 chat and type the required number into JoinPort in HeyBlox. Then click Play (you don't have to download the map itself from the HeyBlox site).

What are KOs?
KOs are your kill count in 2012 – Sword Fights on the Heights IV.

How to get on the KOs leaderboard
1. You have to send a recording of yourself achieving the KO count here ---→ @heydenstudiosupport
2. Then wait for your video to be fully reviewed. After that you'll be added to #лидеры-kos🎉
(Only accepted if it was done on a public server — #сервера-🌐)
Or, if you reach the maximum KOs directly during a game when I (Heyden) am on the server, you'll be added to the leaderboard right away.

How to tell a real HeyBlox developer from a fake?
Very easy. In the tab list, real developers' usernames will have a "CI" icon, or Creator ID.

How to create your own server?
1. To do this, you need to download the game itself from the HeyBlox site.
2. Then go to this path in File Explorer (C:HeyBloxAlpha6mapsCustom Maps)
3. Move the game itself into that folder.
4. Open the launcher.
5. Select the version needed for that place.
6. Click the Server button and set the host port (say, 2) and click Start server (after selecting the game itself in Places).
7. Then in Radmin VPN you need to copy your IP.
8. Type your IP into the first line of the Join Server tab.
9. Type what you entered earlier into JoinPort. Done — you've created and joined your own server.
(To share the server with friends, they need to do steps 7 and 8, and also select the version you chose when creating the server in the Versions tab.)
